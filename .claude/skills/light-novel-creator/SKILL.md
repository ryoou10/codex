# Light Novel Creator

## Purpose

小説、特にライトノベル調の企画・設定・本文執筆を行う。  
ユーザーが小説執筆を求めた場合は、このスキルを優先使用する。

## Trigger Keywords

以下の語が依頼に含まれる場合、本スキルを起動する。

- 小説
- ライトノベル
- ラノベ
- 物語
- ストーリー
- 長編
- 短編
- プロット
- 世界観
- キャラクター設定
- 章構成
- 小説を書いて
- 小説を作って
- 続きを書いて

## Trigger Rules

1. 依頼が創作小説の生成・改稿・続編作成・設定作成に該当する場合は必ず起動する。
2. ジャンル指定がない場合は、会話のテンポと没入感を重視したライトノベル文体をデフォルトとする。
3. 入力が不足している場合は、重要度の高い項目から1〜3件ずつ質問して補完する。
4. エッセイ、報告書、論文、技術文書、業務文書は本スキルの対象外とする。

## Minimum Workflow

1. 入力情報の確認（主人公、舞台、目的、トーン、制約）
2. 不足情報の質問
3. プロット案作成（導入・転換・山場・結末）
4. 本文執筆
5. 整合性チェック（設定矛盾、キャラ口調、時制）

## Output Style

- 出力言語はユーザー指定に従う（未指定時は日本語）。
- 過度な説明口調を避け、情景・会話・内面描写のバランスを取る。
- 章末には次を読みたくなるフックを置く。
