# Claude Code ビルトインスキル・コマンド 日本語リファレンス

Claude Code本体に同梱されているスキルとスラッシュコマンドの日本語対訳。これらの実体はClaude Code本体(パッケージ内部)にあり、編集可能なファイルが存在しないため、`/` メニューでの表示は英語のまま変更できない。意味を確認したいときはこのファイルを参照する。

このプロジェクト独自のカスタムスキル(`.claude/skills/` 配下、日本語説明付き)の一覧は `CLAUDE.md` セクション9を参照。`/` メニューにはビルトインとカスタムの両方が表示される。

注意: ビルトインの構成は環境(ローカルCLI / Web版)やバージョンによって異なる。ここには代表的なものを記載する。

## ビルトインスキル

### 開発・レビュー系

| スキル | 説明 |
|---|---|
| `code-review` | 現在の差分(diff)のバグや改善点をレビューする。`--comment` でPRコメント投稿、`--fix` で修正適用も可能 |
| `review` | Pull Request全体をレビューする |
| `security-review` | 現在のブランチの変更に対するセキュリティレビューを行う |
| `simplify` | 変更したコードの簡素化・再利用・効率化のクリーンアップを適用する(バグ探しはしない) |
| `verify` | 変更が実際に動くか、アプリを起動して動作を観察・検証する |
| `run` | プロジェクトのアプリを起動して動作確認やスクリーンショット取得を行う |

### 設定・環境系

| スキル | 説明 |
|---|---|
| `update-config` | `settings.json` の設定変更(権限・hook・環境変数など)。「今後自動でXして」系の依頼はこれでhookを設定する |
| `keybindings-help` | キーボードショートカットのカスタマイズ(`~/.claude/keybindings.json`) |
| `fewer-permission-prompts` | よく使う読み取り系コマンドをallowlist化し、許可プロンプトを減らす |
| `session-start-hook` | Claude Code on the web用のSessionStart hook(セッション開始時のセットアップ処理)を作る |
| `init` | コードベースを解析して `CLAUDE.md` を新規作成する |

### 調査・実行系

| スキル | 説明 |
|---|---|
| `deep-research` | Web検索を多方面に展開し、出典の検証付きで調査レポートを合成する深掘りリサーチ |
| `claude-api` | Claude API / Anthropic SDKのリファレンス(モデルID・料金・パラメータ・ツール使用・キャッシュなど) |
| `loop` | プロンプトやスラッシュコマンドを一定間隔で繰り返し実行する(例: `/loop 5m /foo`) |

## ビルトインのスラッシュコマンド(スキル以外)

`/` メニューにはスキルのほかに、Claude Code本体の操作コマンドも表示される。これらも英語表記のまま変更できない。

| コマンド | 説明 |
|---|---|
| `/clear` | 会話履歴をクリアして新しく始める |
| `/compact` | 会話履歴を要約して圧縮する(コンテキスト節約) |
| `/config` | テーマ・モデル・言語などの基本設定を開く |
| `/context` | 現在のコンテキスト使用状況を表示する |
| `/cost` | 現在のセッションのトークン使用量・コストを表示する |
| `/doctor` | Claude Code環境の診断を行う |
| `/help` | ヘルプを表示する |
| `/hooks` | hookの一覧・編集メニューを開く(設定の再読込にも使える) |
| `/init` | CLAUDE.mdを新規作成する |
| `/mcp` | MCPサーバーの状態確認・管理を行う |
| `/memory` | CLAUDE.mdなどのメモリファイルを開いて編集する |
| `/model` | 使用するモデルを切り替える |
| `/permissions` | ツールの許可ルールを確認・編集する |
| `/resume` | 過去のセッションを再開する |
| `/rewind` | ファイル変更や会話をチェックポイントまで巻き戻す |
| `/status` | アカウント・接続状態を表示する |
| `/usage` | プラン使用量を表示する |

## Macの `~/.claude/skills` に古いコピーがある場合

handoffの `install-to-claude.sh` を実行した場合、`~/.claude/skills` に変換前の英語版スキル(YAML不備で説明が表示されないものを含む)がコピーされている可能性がある。このリポジトリの `.claude/skills/` が最新版のため、ユーザースコープでも使いたい場合はMac側で次のように入れ替える:

```bash
cd <このリポジトリのパス>
for s in .claude/skills/*/; do
  name="$(basename "$s")"
  rm -rf ~/.claude/skills/"$name"
  cp -R "$s" ~/.claude/skills/"$name"
done
```

このリポジトリをプロジェクトとして開いて使うだけなら、`~/.claude/skills` へのコピーは不要(プロジェクトスコープで自動読込されるため、重複表示を避けるには入れない方がよい)。
