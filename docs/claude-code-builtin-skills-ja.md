# Claude Code ビルトインスキル 日本語リファレンス

Claude Code本体に同梱されているスキルの日本語対訳。`/` メニューでの表示は英語のまま変更できないため、このファイルを参照する。

注意: ビルトインスキルの構成は環境(ローカル / Web版)やバージョンによって異なる。ここには代表的なものを記載する。

## 開発・レビュー系

| スキル | 説明 |
|---|---|
| `code-review` | 現在の差分(diff)のバグや改善点をレビューする。`--comment` でPRコメント投稿、`--fix` で修正適用も可能 |
| `review` | Pull Request全体をレビューする |
| `security-review` | 現在のブランチの変更に対するセキュリティレビューを行う |
| `simplify` | 変更したコードの簡素化・再利用・効率化のクリーンアップを適用する(バグ探しはしない) |
| `verify` | 変更が実際に動くか、アプリを起動して動作を観察・検証する |
| `run` | プロジェクトのアプリを起動して動作確認やスクリーンショット取得を行う |

## 設定・環境系

| スキル | 説明 |
|---|---|
| `update-config` | `settings.json` の設定変更(権限・hook・環境変数など)。「今後自動でXして」系の依頼はこれでhookを設定する |
| `keybindings-help` | キーボードショートカットのカスタマイズ(`~/.claude/keybindings.json`) |
| `fewer-permission-prompts` | よく使う読み取り系コマンドをallowlist化し、許可プロンプトを減らす |
| `session-start-hook` | Claude Code on the web用のSessionStart hook(セッション開始時のセットアップ処理)を作る |
| `init` | コードベースを解析して `CLAUDE.md` を新規作成する |

## 調査・実行系

| スキル | 説明 |
|---|---|
| `deep-research` | Web検索を多方面に展開し、出典の検証付きで調査レポートを合成する深掘りリサーチ |
| `claude-api` | Claude API / Anthropic SDKのリファレンス(モデルID・料金・パラメータ・ツール使用・キャッシュなど) |
| `loop` | プロンプトやスラッシュコマンドを一定間隔で繰り返し実行する(例: `/loop 5m /foo`) |

## このプロジェクトのカスタムスキルとの関係

`.claude/skills/` 配下のカスタムスキル(日本語説明付き)の一覧は `CLAUDE.md` セクション9を参照。ビルトインとカスタムは併存し、`/` メニューには両方が表示される。
