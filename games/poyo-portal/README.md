# ポヨ＆ポータル 〜ふしぎなワープのぼうけん〜

カービィ風の「吸い込み＆ふわふわ浮遊」アクションと、Portal風の「ポータルガン」パズルを
組み合わせたオリジナル2Dアクションゲームです。PC・スマホ両対応、依存ライブラリなしの
単一HTMLファイル（`index.html`）で動作します。

※ キャラクター・ステージ・名称はすべてオリジナルです（任天堂・Valveの素材は使用していません）。

## 遊び方

`index.html` をブラウザで開くだけ。ローカルサーバーを使う場合：

```bash
cd games/poyo-portal
python3 -m http.server 8000
# → http://localhost:8000 を開く（スマホは同じWi-FiからPCのIPでアクセス）
```

## 操作方法

### PC（キーボード＋マウス）
| 操作 | キー |
|---|---|
| 移動 | ← → / A D |
| ジャンプ | Space / W（空中でもう一度＝ふわふわ浮遊。息ゲージを消費） |
| 吸い込み / 吐き出し | X / J / E（長押しで吸い込み → もう一度押して星をはき出す） |
| 青ポータル | 左クリック |
| 橙ポータル | 右クリック |
| リスタート | R |

### スマホ（タッチ）
- 画面左の **◀ ▶** ボタンで移動
- **ジャンプ** ボタン：空中でもう一度押すとふわふわ浮遊
- **すいこみ** ボタン：長押しで吸い込み、口に入れたらもう一度押して星をはき出す
- **画面タップ**：タップした方向にポータル発射（青 → 橙の交互）
- 右上の **⟳** でリスタート

## ルール
- 白っぽい土ブロック（`#`）にだけポータルが開く。灰色の金属（`X`）には開かない
- 2つのポータルをつなげるとワープ。**落下の勢いはワープ後も保存される**ので、
  高い所から落ちてポータルに入れば大ジャンプ・大発射ができる
- 敵を吸い込んで星をはき出せば倒せる。トゲと敵に当たるとダメージ（ハート5つ）
- ゴールの大きな星に触れるとステージクリア。全3ステージ
