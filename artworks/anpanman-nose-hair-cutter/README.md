# Anpanman Nose Hair Cutter Henachoko Artwork

This folder contains a deliberately clumsy, painterly fan-art style image of Anpanman using a nose hair cutter.

- Generated asset: `anpanman-nose-hair-cutter-henachoko.png`
- Generator: `generate.py`
- Style target: intentionally awkward, hand-painted, wobbly outlines, warm canvas texture, and comic motion marks.
- Scene target: Anpanman-like round-faced hero holds a nose hair trimmer up to his nose with a sheepish expression.

The generator uses only Python standard-library modules and writes an uncompressed 24-bit PNG image so it can run in minimal environments without external image libraries.
